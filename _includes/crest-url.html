{%- comment -%} Resolves a team's crest to a URL, or an empty string if we do not have one. Split out from team-crest.html so the fixture cards and the JSON payload that feeds the details pop-up agree on where a crest lives. Params: slug {%- endcomment -%} {%- assign club = site.data.club -%} {%- assign crest = '' -%} {%- comment -%} A club written more than one way in the calendar gets pointed at one file by crest_aliases in club.yml, so "Raptors 4" finds the Cardiff Raptors badge without a second copy of the image. {%- endcomment -%} {%- assign slug = include.slug -%} {%- if club.crest_aliases and club.crest_aliases[slug] -%} {%- assign slug = club.crest_aliases[slug] -%} {%- endif -%} {%- if slug == club.crest_slug -%} {%- assign crest = club.crest -%} {%- else -%} {%- comment -%} Falls back to a built-in list if site.crest_formats is missing. Jekyll does not reload _config.yml while `--watch` is running, so a dev server started before that key existed would otherwise loop over nothing and quietly show initials for every team. {%- endcomment -%} {%- assign formats = site.crest_formats -%} {%- if formats == nil or formats.size == 0 -%} {%- assign formats = 'webp,png,svg,jpg,jpeg' | split: ',' -%} {%- endif -%} {%- for ext in formats -%} {%- if crest == '' -%} {%- assign candidate = '/assets/images/teams/' | append: slug | append: '.' | append: ext -%} {%- comment -%} The lookup has to be assigned before it is tested. Liquid does not evaluate filters inside an if condition: it tests the left-hand value alone and ignores the rest of the pipeline. site.static_files is always a non-empty array, so testing it directly matched on the first extension every time and emitted an img pointing at a file that was never there. {%- endcomment -%} {%- assign hit = site.static_files | where: 'path', candidate | first -%} {%- if hit -%} {%- assign crest = candidate -%} {%- endif -%} {%- endif -%} {%- endfor -%} {%- endif -%} {{- crest -}}
