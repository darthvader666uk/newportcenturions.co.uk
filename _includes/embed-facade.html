{%- comment -%} Click-to-load facade for third-party iframes (YouTube, Google Maps). Both embeds previously loaded on page view, which set third-party cookies before the visitor had consented to anything — the same PECR/UK GDPR problem the analytics banner solves. They also cost ~600KB (YouTube) and ~1MB (Maps) on pages that mostly don't need them. Nothing is requested from the third party until the visitor clicks. Parameters: type - "youtube" | "map" (required) src - full iframe src (required) title - accessible iframe title (required) label - button text (optional) ratio - aspect-ratio CSS value (optional, default 16 / 9) {%- endcomment -%} {%- assign ratio = include.ratio | default: '16 / 9' -%} {%- if include.type == 'youtube' -%} {%- assign default_label = 'Load video' -%} {%- assign provider = 'YouTube' -%} {%- assign icon = 'fa-brands fa-youtube' -%} {%- else -%} {%- assign default_label = 'Load map' -%} {%- assign provider = 'Google Maps' -%} {%- assign icon = 'fa-solid fa-location-dot' -%} {%- endif -%} {%- assign label = include.label | default: default_label -%}
